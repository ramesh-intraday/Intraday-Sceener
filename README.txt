INDIA INTRADAY SCREENER - ANDROID PWA

Install:
1. Upload this folder to an HTTPS host such as GitHub Pages, Netlify or Cloudflare Pages.
2. Open the HTTPS URL in Chrome on Android.
3. Chrome menu -> Install app / Add to Home screen.

Features:
- 5m/15m screening
- VWAP, EMA20, EMA50, RSI14, volume spike
- breakout/breakdown confirmation
- ATR/swing-based SL and 1:2 target estimate
- position size from rupee risk
- 25 liquid Indian NSE stocks in the starter universe

Data note:
The demo uses Yahoo Finance chart data through a public CORS proxy for convenience. It may be delayed or rate-limited and is not an exchange-grade feed. Verify everything in INDmoney.
For production/live trading, connect an authorized real-time market-data vendor or broker API.
